# Cudy R76 reconstruction reference

Selected evidence from the user-supplied Cudy_AX1500_Vollanalyse archive.
These files are reference material only, not part of a firmware build.
Reconstructed C is not original manufacturer source; retain individual
provenance and license notices. The kernel/firmware/module binaries, full
RootFS, private configuration and automatic Ghidra output are not copied here.
manifest.json records archive provenance and every retained file hash.

Our Ethernet emulation rerun: 3591 cases pass against the hash-matched OEM
kernel. Firmware hardware behavior, radio calibration and physical timing are
not validated by emulation. Linux changes and integration decisions are in
reverse-engineering/wr1500-wifi6/R76-FULL-ANALYSIS-PORT.md.
