[RTL839xM][OAM] Add ETH-DM RX timestampe get API.
Enhancement:
	(1) Add rtk_oam_cfmEthDmRxTimestamp_get() to get RXTimeStamp by index.
	(2) Add "oam get cfm eth-dm rx-timestamp index <UINT:index>" diag shell command.
How to turn on this feature:
    The ETH_DM and PTP functions share the same entity of clock, so PTP reference-time-related
    commands could be used to control ETH_DM time clock.
