# Analyse-Dateien

- `dateien_inventar.csv`: alle im Paket enthaltenen Dateien mit Kategorie, Größe, Keywords und Hash für kleinere Dateien.
- `config_matrix.csv`: wichtige Kernel-/Backports-/Preconfig-Flags für RTL8197F/RTL8367R(B)-Targets.
- `uboot_config_matrix.csv`: wichtige U-Boot-Flags für 8197F + 8367RB/8367R-Defconfigs.
- `file_tree_selected.txt`: Dateiliste des fokussierten Extrakts.
- `relevante_rg_treffer.txt`: Roh-Treffer der Quelltextsuche.
