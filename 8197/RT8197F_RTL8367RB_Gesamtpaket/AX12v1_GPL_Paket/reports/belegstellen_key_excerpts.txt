===== build_install =====
--- INSTALL.txt:1-80 ---
00001: 0. Introduction
00002:    This file will show you how to build the RTL8197H linux system.
00003:    Besides, It will guide you how to download the built image to Realtek EV (Evaluation) board 
00004:    for testing. PLEASE NOTE, the download image will overwrite the original image existed in the 
00005:    flash memory of EV board.
00006: 
00007: 1. Build Environment
00008: 	CentOS Linux release 7.6.1810 (Core)
00009: 	Ubuntu 16.04
00010: 
00011: 2. Quick start
00012:    - tar -jxvf rtl819x.tar.bz2
00013:    - cd rtl819x/
00014:    - make menuconfig:
00015: 	--for SPINAND_RTL8197F_VG_8832BR_8367R_Kernel4.4_GW
00016: 		Selected Target (rtl8197F)
00017: 		Selected Kernel (linux-4.4)
00018: 		Selected Busybox (busybox-1.24.1)
00019: 		Selected toolchain (msdk-6.4.1-mips-EL-4.4-u0.9.33-m32ut-190619)
00020: 		Selected Board Configuration (SPINAND RTL8197F_VG/8832BR+8367R Kernel4.4 GW)
00021: 		Select Load default settings
00022: 
00023: 	--for SPINAND_RTL8197F_VG_8832BR_8367R_Kernel4.4_GW_EASYMESH
00024: 		Selected Target (rtl8197F)
00025: 		Selected Kernel (linux-4.4)
00026: 		Selected Busybox (busybox-1.24.1)
00027: 		Selected toolchain (msdk-6.4.1-mips-EL-4.4-u0.9.33-m32ut-190619)
00028: 		Selected Board Configuration (SPINAND RTL8197F_VG/8832BR+8367R Kernel4.4 GW_EASYMESH)
00029: 		Select Load default settings
00030: 
00031: 	
00032:    - make
00033: 	
00034: 3. make image
00035:    there are four steps for making image:
00036:    - make users
00037:      build the users applications
00038:    - make linux
00039:      build the kernel files
00040:    - make romfs
00041:      copy all the application binary files into romfs
00042:    - make image
00043:      compress the root.bin and linux.bin
00044: 
00045: 4. build bootloader
00046:    - cd rtl819x-SDK-v3.6.0-full-package
00047:    - tar jxvf rtl819x-SDK-v3.6.0-bootcode.tar.bz2
00048:    - cd bootcode
00049:    - ensure the source code of sdk is existent, do command "tar -jxvf rtl819x.tar.bz2" first, it include the toolchain.
00050:    - add environment variable(assume you source code directory is /rtl819x-SDK-v3.6.0-full-package/bootcode):
00051:        --for rtl8197F
00052:                  "PATH=$PATH:../rtl819x/toolchain/msdk-4.4.7-mips-EL-3.10-u0.9.33-m32t-140827/bin"
00053: 
00054:    - cp def-rtl8197fh_vg_8367rb_vc-spi_nand-config .config (It will do the default setting for rtl8197F bootcode.)
00055:    - make menuconfig:
00056:    - Exit and Save	
00057:    - make 
00058:    - you will find boot.bin in ./btcode_vg
00059:    - 'boot.bin' is the bootloader image
00060: 
00061: 5. binary file list
00062:    - rtl819x/image/fw.bin                    : the image include root.bin,linux.bin and webpages-gw.bin
00063:     	  
00064: 6. Download image files to Realtek EV (evaluation) board for testing
00065:    - Use a RS232 cable to connect COM port between a LINUX PC and EV board.
00066:    - Connect LINUX PC Ethernet port to the LAN port of EV board. Set PC IP
00067:      address to 192.168.1.x (e.g., type 'ifconfig eth0 192.168.1.1').
00068:    - Start a COM port console (e.g., minicom), and set COM port setting to
00069:      38400, 8N1 and no flow control.
00070:    - Power on EV board, and press 'ESC' key in COM port console to escape the
00071:      booting process. If ok, you may see "<RealTek>" prompt in the console.
00072:    - Start a TFTP client in LINUX PC, and connect to 192.168.1.6. Set file
00073:      type to binary mode to TFTP server of EV board, put root.bin if gw 
00074:      platform to TFTP server, and put root image file(rtl819x/image/root.bin) to TFTP server,
00075:      then put the webpages image file and  linux image files to TFTP server.
00076:      After linux.bin file upload had finished, boot code will auto booting.
00077:    - NOTE:you can do the same thing on Windos PC.
00078: 
00079: 7. Build ramdisk for MP using "root" user
00080:    - modify /etc/fstab
