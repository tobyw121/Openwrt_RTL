This archive is for private OpenWrt porting analysis.
It can contain device MAC addresses, serial numbers, WLAN configuration,
calibration/eFuse-derived data, process maps, credentials and cloud settings.
Do not publish it unredacted.

Collector safety:
- no flash erase/write was performed
- no GPIO value/direction was written
- no switch/PHY/SoC register was written
- no kernel module was unloaded/reloaded
- no watchdog device was opened
