# MW5 v43.7 operator test

After flashing and booting, use the serial console and run only:

    mw5-netdiag

Have a PC with its Ethernet adapter on DHCP/automatic.  Start with its cable in
the MW5 LAN jack.  The script first checks normal br-lan/LAN and then direct
LAN.  When it tells you to, move the same cable to the WAN jack for direct WAN.
After restoring the normal network it also checks routed WAN DHCP.  For a real
WAN lease, the WAN cable must lead to an upstream DHCP router; a direct PC link
will correctly be reported as NO-LEASE.  All router-side commands, traffic
generation, state capture, counter comparison, and restore are automatic.

The final concise result is written to:

    /tmp/mw5-diag/autotest-summary-latest.txt

The full invocation log is available through:

    /tmp/mw5-diag/latest.txt

No firewall rules are active in this v43.7 diagnostic image.  firewall4 is
disabled, `/etc/config/firewall` is intentionally empty, and nftables is
flushed.  This is intentional for datapath bring-up and is not a production
security configuration.
