RTL8197F / Tenda Nova MW5 v43.12 static validation
===================================================

Scope
-----
v43.12 changes the DSA CPU-to-switch four-byte tag only. The stable v43.11
RTL8197F DMA/FCS/KSEG1/ring-completion logic is intentionally retained.

Expected tag arithmetic
-----------------------
protocol = 0x9
LAN port 1 mask = BIT(1) = 0x02 -> tag 0x9002
WAN port 3 mask = BIT(3) = 0x08 -> tag 0x9008
Observed RX LAN tag remains 0x0401.

Hardware evidence motivating the change
---------------------------------------
v43.11 eliminated RX descriptor corruption and TX ring stalls: the captured
run reached 244 TX submissions and 244 completions with zero ring-full, busy
or timeout events, while DSA user-port TX counters remained zero and ping still
failed. The tagger was emitting 0x9202/0x9208. v43.12 removes only the
unverified 0x0200 bit.

Limitations
-----------
No complete OpenWrt MIPS cross-build was run in this environment.
No claim of v43.12 hardware success is made until it is built/flashed/tested on
the user's MW5.
