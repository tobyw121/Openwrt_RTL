# Tenda Nova MW5 v43.6 build fix

## Observed build result

The supplied log ends with `scripts/Makefile.build:480: net Error 2`, while the
kernel compile commands contain global `-Werror`. The primary GCC diagnostic
was not included in the copied tail.

## Reproduced source defect

The v43.5 tagger logged the destination mask with `%x` but supplied
`BIT(dp->index)`. Linux defines `BIT()` as an unsigned-long expression. GCC's
format checker therefore reports an incompatible `%x` argument, and `-Werror`
turns that warning into a build failure.

## v43.6 implementation

```c
u32 port_mask;

port_mask = BIT(dp->index);
...
FIELD_PREP(RTL4_9_PORT, port_mask);
...
netdev_info(dev, "... mask=0x%x ...", port_mask);
```

The v43.5 MAC reseed, RX EtherType reconstruction and built-in diagnostics are
retained unchanged apart from version markers.

## Build

```sh
make target/linux/clean
make target/linux/compile -j1 V=s
make -j"$(nproc)" V=s
```

The serial build (`-j1 V=s`) should be retained for the first retry so any
further primary compiler diagnostic cannot be hidden by parallel output.
