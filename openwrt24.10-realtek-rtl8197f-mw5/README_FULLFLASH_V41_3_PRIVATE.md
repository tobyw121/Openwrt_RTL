# PRIVATE automatic fullflash build - v41.3

This tree contains board-matched private SPI templates for RD05, MW5 and AC23.
Do not publish the tree or generated images.

## MW5-specific boot format

The Tenda RTL8197F bootloader does not accept a normal OpenWrt SquashFS by
itself. v41.3 runs `scripts/rtl8197f-rootfs-checksum.py` before embedding the
MW5 rootfs. The builder then validates both:

1. the `cr6c` kernel/header checksum; and
2. the separate SquashFS trailer checksum.

A missing or invalid rootfs checksum stops image generation.

## Build all devices

```sh
./BUILD_ALL_FULLFLASH_V41_3.sh
```

## Build only MW5

```sh
./BUILD_RTL8197F_V41_3.sh configs/rtl8197f_mw5_defconfig
```

Use a serial console at 115200 8N1 and keep an external SPI programmer plus an
unaltered board-specific backup available. Never flash an image generated by
v41.1/v41.2 on MW5.
